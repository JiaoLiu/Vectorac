## 串口调试

页面下方「串口调试」面板是独立的串口收发工具，不走刷写协议，可以用来：

- 烧录完成后查看设备启动日志、运行日志
- 主动给设备发送 AT 命令、调试指令、JSON 配置等
- HEX 模式收发二进制数据

> 串口调试和上方烧录区**不能同时连接**。需要调试时先点上方「断开」，再到下方点「连接串口」。

## 使用步骤

1. **准备硬件**：用 USB 数据线把设备接到电脑（确认是数据线，不是纯充电线）。
2. **进入下载模式**：按住板子上的 `BOOT` 按键，按一下 `RST` 按键，松开 `BOOT`。成功后设备管理器里会看到一个新的串口。
3. **打开本页**：用 Chrome 89+ 或 Edge 89+ 访问本页（线上必须是 `https://`）。
4. **选固件**：上方下拉框选择要烧录的版本，下方会显示文件路径、地址、Flash 模式等信息。
5. **点「连接串口」**：浏览器会弹窗让你选择串口，选刚出现的 ESP 设备串口即可。
6. **点「开始烧录」**：自动下载固件 → 擦除 → 写入 → 校验 → 硬复位，全程进度条 + 终端日志可见。
7. **完成**：看到 `✓ 已硬复位，固件已启动` 后，按一下 `RST` 让固件正式运行。

> 如果需要清空设备（比如换大版本时分区表变了），勾上「刷写前擦除整片 Flash」。

## 浏览器与协议要求

| 维度 | 要求 |
| --- | --- |
| 浏览器 | Chrome / Edge 89+，或任何支持 [Web Serial API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API) 的浏览器 |
| 协议 | HTTPS 或 localhost（Web Serial 仅在安全上下文可用） |
| 系统 | Windows / macOS / Linux / ChromeOS 均可 |
| 手机 | Android Chrome 61+ 支持，iOS 暂不支持 |
| 芯片 | 当前仅支持 ESP32 / ESP32-S2 / ESP32-S3 / ESP32-C3 等 Espressif 系列 |

## 常见问题

**Q: 浏览器弹不出串口选择框？**
A: 确认三件事：① 用 Chrome/Edge 89+；② 线是 USB 数据线（很多 Type-C 线只能充电）；③ 设备已进入下载模式（BOOT + RST）。Windows 上还要确认驱动装好（CP210x / CH340 等）。

**Q: 烧到一半卡住或失败？**
A: 换一根更短的 USB 数据线；避开 USB 集线器；尝试勾选「擦除整片 Flash」后重试。多次失败可联系开发团队排查固件兼容性。

**Q: 能刷非 ESP 芯片（STM32 / GD32 等）吗？**
A: 当前仅支持 Espressif ESP32 系列（含 S2 / S3 / C3 等）。如有其他芯片需求可联系开发团队评估。

**Q: 离线还能用吗？**
A: 浏览器会缓存已访问过的固件文件和页面资源，首次刷写后即便断网也能正常使用（前提是页面已进浏览器缓存）。

**Q: 安全吗？会不会有人远程刷我板子？**
A: 不会。每次烧录都需要您**主动点击**「连接串口」并在浏览器弹窗里授权对应设备，固件虽然托管在网站，但「能不能写到芯片」完全由本机用户控制。
