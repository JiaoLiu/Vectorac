# 经典标准批：规则核对与验收边界

规则冻结为经典实体原版标准25，不包含界／谋／OL加强技能。完整映射在canonical-roster.mjs；参考名与原技能名只用于核对，表现层使用神话名称和原创插画。

## 容易混淆的历史规则

- 观星：准备阶段看存活人数、最多5张，不套用新版“至多3人看3张、否则看5张”或结束阶段二次观星。
- 离间：弃一张手牌或装备，让两名其他男性进行指定方向决斗；经典原版不能无懈。决斗来源是男性发起者，不是技能使用者；空城禁止成为决斗目标，但可作为决斗使用者。
- 遗计：每点伤害分别处理2张新牌，仅这些新牌可分配，不采用新版任意旧手牌赠送上限；死亡后不触发。
- 鬼才：一张手牌替换，不采用张角鬼道的黑色装备改判。天妒只取得最终判定牌，替换掉的旧判定牌弃置。
- 结姻：一次出牌阶段弃2张手牌，自己与一名受伤的其他男性各回1；不能给牌替代弃牌。
- 枭姬：装备区每失去一张摸2，包括替换、偷取、弃置及技能消耗；死亡清理不触发。借刀交出武器也属于失去装备。
- 急救：回合外红色手牌或装备当桃，自己的整段回合不能转化；青囊一次出牌阶段弃1手牌，可治疗自己。
- 谦逊：不能成为顺手／乐目标，不阻止过河／决斗。空城只检查新目标声明，不使已经声明的攻击自动作废。
- 流离：排除原攻击者；弃置武器或进攻坐骑时用失去该装备后的范围判断。
- 克己：出牌阶段没有使用或打出杀，才能免弃；在自己出牌阶段决斗中响应杀也会失去免弃资格。
