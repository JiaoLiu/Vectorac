# 三国·逐鹿（单机经典身份版）

官网路径：`/blogs/other/sanguo.html`。游戏大厅使用普通链接整页进入，HTML 首次解析便获得 `viewport-fit=cover`。

## 本版范围

- 五人身份：1 主公、1 忠臣、2 反贼、1 内奸；人类固定逻辑座位 0。
- 12 名经典武将：刘备、关羽、张飞、赵云、马超、黄月英、孙权、黄盖、周瑜、曹操、许褚、吕布。所有列出的技能有真实规则实现，包括激将、护驾、救援。
- 标准与 EX 牌表共 108 张，32 种牌名；53 基本、36 锦囊、19 装备。花色和点数固定，每次洗牌种子可重现。
- 不包含军争、国战、界限突破、其他扩展武将或联机。
- 经典技能为依据，独立实现；技能说明为简短转述，封面、牌面、徽像和界面均为原创。

## 分层与规则

`catalog.mjs` 保存牌表、武将、技能与官方参考链接。
`engine.mjs` 为纯状态机。`dispatch` 克隆状态后验证动作；非法动作原子拒绝。结算队列、响应窗口、待结算实体牌区、牌堆/弃牌堆、装备和判定区均可序列化。
`ai.mjs` 只接收 `playerView`：自己手牌、公开信息、合法动作和行为推断。不得传入原始状态、牌堆或对方身份/手牌。主公公开，其他身份阵亡或终局后公开。
`ui.js` 处理触摸选择、目标、确认、对局节奏和视图；使用 `sanguo.css` 的独立样式命名空间。原始座位和牌 ID 不随横竖屏变化。

响应覆盖杀/闪、无双连续响应、丈八转化、无懈及反无懈、濒死多桃、八卦、主公援助、奸雄、铁骑、裸衣、英姿、集智、反间、双股剑、青龙刀、贯石斧、寒冰剑、麒麟弓、五谷选牌及区域选牌。
阵亡即时检查胜负，回合内阵亡自动跳过后续阶段。击杀反贼奖励三牌；主公误杀忠臣丢弃手牌和装备。
无懈逐角色抵消效果；延时锦囊在判定前进入反制窗口。结算中的实体牌不参与弃牌洗回，避免正在生效的牌被重新抽走。
指定目标时的铁骑、雌雄双股剑先结算，再检查仁王盾让黑色杀无效；不能提前跳过此前触发效果。依据官网 2.70 规则优化公告：<https://www.sanguosha.com/news/20151112_1807_1410>。

## 自动存档

- `vectorac.sanguo.save.v1`：状态及本局统计是否已登记。
- `vectorac.sanguo.prefs.v1`：音效、AI 动作间隔。
- `vectorac.sanguo.stats.v1`：本地终局与胜局次数。

每个合法动作保存。刷新后从点将台继续；保留当前响应窗口。恢复校验 108 张实体牌的唯一性和牌面字段、武将/身份、结算事件及响应结构。版本不兼容或损坏时忽略存档并回到点将台。不会改动其他游戏的本地存储。
隐藏页面、暂停、规则对话框和反馈窗口期间不推进 AI。销毁实例时清理计时器、音频和监听并恢复原页面滚动。

## 验收与发布

```bash
npm run test:sanguo
npm run build
npm run test:sanguo:browser
SANGUO_TEST_URL=https://vectorac.com npm run test:sanguo:browser
```

浏览器测试使用隔离 Chrome/CDP，不依赖 Playwright。包含 390×844、844×390、667×375、320×568、1280×900；真实触摸事件、双闪、求桃、存档、暂停、长手牌、五谷与对手全可视。属于浏览器模拟，不等同于物理 iPhone/Android 验收。
发布使用当前完整工作区构建，确认 nginx 根目录 `/home/www/vectorac/dist`，先 `rsync -rt --dry-run` 再同步；不使用 `--delete`，保留服务器维护的资源。服务器不构建或安装 npm。
