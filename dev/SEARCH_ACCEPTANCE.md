# 官网搜索范围验收

2026-10-13，本地构建与官网实际搜索验收完成，已发布。发布记录见 [RELEASE_20261013.md](RELEASE_20261013.md)。

- 内部文档在仓库 `dev/`，位于 VuePress 源目录 `site/` 之外；页面收集进一步采用白名单，只生成首页、两个公开博客目录及公开联系页。
- 顶部搜索沿用当前主题的外观、标题/章节匹配、数量上限和跳转，只将 `blogs/other`、`blogs/timeline` 的公开页面交给搜索匹配。`search: false`、`draft: true` 或 `published: false` 的博客不进入搜索建议。
- 配置与边界测试通过；网站完整构建通过。构建目录中无开发规范、目录说明、迁移验收或 `AGENTS.md` 页面，生成的页面数据无内部文档。
- Chromium 实际输入“1”“图表”“公司成立”“在线演示”“部署”，得到公开博客标题或章节，点击建议正常跳转。输入开发规范及内部文档名称，无结果。
- 在隔离浏览器中额外加入与公开文章同名的开发文档、联系页、分类页和未公开博客，实际搜索建议仍将它们排除，避免只靠当前文档恰好没有被构建来判断正确。
- 浏览器、临时服务及测试目录在结束时清理；本轮没有生成额外截图。用户提供的截图保留。

后续检查：`npm run test:search`、`npm run test:search:browser`。完整构建的 `postbuild` 也执行页面与搜索边界测试。源码生成规则与顶部搜索范围同时维护，新增页面不能默认扩大搜索到内部文档。
