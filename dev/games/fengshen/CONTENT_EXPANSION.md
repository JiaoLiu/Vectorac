# 众神斗法：人物与法宝扩展总表

> 历史候选草案，非当前将池。2026-10-10起以CANONICAL_MAPPING.md为准：54人形象图鉴、经典标准25人可玩、32类卡牌／108张实体牌。下方43人混搭／121牌记录已废止；法宝扩展机制仅在隔离实验测试中保留，风火林山与一将成名按完整原武将分批实现。

## 范围与完成状态

用户已确认“直接实装并上线，分批扩充”。当前52人图鉴、43人可玩，39类卡牌；下面的长期目录目标为100个人物候选、60件法宝／坐骑候选。**候选不是已上线数量**，不提前把未实现角色塞进选将，不以换皮组合冒称完整复刻另一游戏的武将。

人物目录计算：原20位封神人物 + 本批12位 + 后续48位 = 80位封神线角色；加已接入20位世界神话角色，共100位候选。神话国籍只管展示，主公响应依旧按青、赤、金、玄同盟，不把全世界神祇默认编为同一阵营。

法宝目录计算：当前21种装备／坐骑 + 后续39件候选 = 60件。部分未来法宝应做锦囊、延时阵法或角色专属效果，**不是60种都挤进武器栏**；当前39类卡牌还包含基本牌与锦囊，并不等于39件装备。

所有匹配是策划选择。三国杀明确按标准技能原理、具体扩展版本分别核对；英雄杀只将相近玩法列为候选，不混入闯关宝具、付费强化、觉醒或等级加成。独立制作美术与技能文案，不能凭改名换图认定发行授权或商业审查已经完成。
