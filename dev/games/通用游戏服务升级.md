# 麻将服务升级为通用游戏服务

## Context

现有 `mahjong-service/` 只支持麻将。用户要求四国军棋（4人2v2）、中国象棋（2人）、五子棋（2人）全部接入同一套房间体系：语音消息、座位、分享链接、ready/多局/破产机制复用；**所有游戏共用一个大厅，全局共享 20 房间上限**（config.maxRooms=20 已是全局）；不同游戏注入不同引擎/AI/规则。

已核实的关键事实：
- 服务端 `rooms/game-session.js` 已通过 5 个引擎函数驱动牌局（createGame/dispatch/legalActions/playerView/settlementOf），是天然的适配器雏形；麻将耦合点集中在：窗口三函数（game-session.js:62-133）、matchesLegalOption（action-window.js:57）、fallbackAction（ai-jobs.js:25）、sanitizeRules/nextDealerOf/_launchRound（room.js）、createSeats(4)/%4（seat.js）、4人视角旋转（serializer.js）。
- 三个游戏引擎均为纯 ESM 零 DOM，可直接服务端 import：军棋 `engine.mjs`（含 rollOpening 掷骰定先手、restoreGame 反作弊、内置 LCG 种子）、象棋 `engine.mjs`（AI 支持注入 rng）、五子棋 `engine.js`+`ai.js`（negamax，4 处 Math.random 需改注入 rng）。
- net-client.js 游戏无关（仅默认 wsPath 带麻将名，已参数化）；WS 路径 `/mahjong-ws` 只是字符串，nginx 零改动即可兼容现有分享链接。
- mahjong-service 是 ESM（"type":"module"）。

## 已定决策（用户确认）

- **先后手**：象棋/五子棋首局房主选边（建房参数 hostSide），之后每局自动换先；军棋沿用引擎 rollOpening 掷骰定先手。
- **AI 补位**：所有游戏允许 AI 随时补位（同麻将现状），真人进房顶替 AI。
- **先后手/禁手从简**：五子棋保持 ≥5 即胜无禁手；休闲产品不做三手交换。

## 架构：GameAdapter 接口

新建 `mahjong-service/rooms/adapters/` 注册表，每个游戏一个适配器：

```js
{
  gameId: 'mahjong'|'junqi'|'xiangqi'|'gomoku',
  seatsPerRoom: 4|2,
  defaultRules, sanitizeRules(input),          // 麻将现有 RULE_RANGES 逻辑迁入
  openingFor(room, roundCtx, rng),             // 开局仪式钩子 → { engineInit, ceremony, firstMoverSeat }
  createState(engineInit, seats, rules),
  dispatch(state, action), legalActions(state, seat),
  playerView(state, seat), settlementOf(state),// settlement → { perSeat:[{seat,delta}] }
  isFinished(state),
  windowIdentityOf(state), windowTypeOf(state), eligibleSeatsOf(state),
  windowTimeoutMs(state, room), matchesLegalOption(legal, action),
  aiDecide(view, level, rng), aiFallback(view, legal),
  serializeView(state, viewerSeat, meta),      // 麻将=4人旋转；2人=简单映射
  nextRoundCtx(room, results, roundCtx),       // 麻将:nextDealerOf；棋类:奇偶局翻转 firstSeat
}
```

`roundCtx = { round, firstSeat, hostSide? }`：棋类 round 1 房主执先，`firstSeat = round%2===1 ? hostSeat : 1-hostSeat`。

## 统一大厅前端

新页面 `blogs/other/gamehall.md` + `site/.vuepress/components/gamehall/GameHall.vue`，net-client.js 直接复用。功能：
- 游戏类型 tab（全部/麻将/军棋/象棋/五子棋）+ 房间列表（gameType 图标、房号、人数 x/N、状态）
- 创建房间：选游戏 → 该游戏规则表单（defaultRules 渲染）→ 2 人游戏选 hostSide（执红/执黑、执黑/执白）
- `?room=CODE` 自动 join（复用 lobby.js:118 模式）；分享链接统一为大厅 URL
- 麻将 lobby.js 暂不动（零风险）；军棋/象棋/五子棋单机页与麻将页各加"联机对战"入口跳 `/gamehall.html?game=xxx`
- 房间内按 gameType 分发渲染对应游戏组件（军棋复用 FourKingdoms 渲染层、象棋/五子棋复用各自 ui 渲染，接 remote-game 数据流——参照麻将 multiplayer/remote-game.js 模式，每游戏一个轻量 remote 壳）

## 各游戏适配器要点

- **五子棋**（P2 首发，链路最简）：seats=2；黑先；delta 胜+10/负-10/和0（100 分起，10 连败破产，与麻将体系兼容）。
- **象棋**：seats=2；红先；resultForSideToMove 出胜负；delta 同五子棋。
- **军棋**：seats=4；`team=seat%2`（0&2 对 1&3）；rules 含 `mode: dark|dual|open`；布阵阶段作为并行窗口（eligibleSeats=未部署完的四家，同麻将换三张模式）；openingFor 调 rollOpening 定先手；胜方每人+10/负方-10。
- **麻将**：纯搬迁，用现有 mahjong-service test.js + 线上回归验证行为不变。

## 协议与部署

Envelope（hub.js:77）不动，playerView payload 由适配器自定。部署同进程同端口，**nginx 零改动**（/mahjong-ws 路径名兼容现有分享链接）；PM2 同进程；目录名 mahjong-service 保留。
